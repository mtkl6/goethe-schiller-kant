# German Classics — Goethe · Schiller · Kant

A single-file collection of the complete available German-language works of Goethe, Schiller, and Kant, sourced from [Project Gutenberg](https://gutenberg.org).

## Contents

| Author | Works |
|--------|-------|
| Johann Wolfgang von Goethe | Faust I & II, Die Leiden des jungen Werthers, Wilhelm Meister, Die Wahlverwandtschaften, Götz von Berlichingen, Iphigenie auf Tauris, Egmont, Torquato Tasso, and more |
| Friedrich Schiller | Die Räuber, Kabale und Liebe, Don Karlos, Maria Stuart, Wilhelm Tell, Wallenstein trilogy, Die Jungfrau von Orleans, Über die ästhetische Erziehung des Menschen, and more |
| Immanuel Kant | Kritik der reinen Vernunft, Kritik der praktischen Vernunft, Kritik der Urteilskraft, Grundlegung zur Metaphysik der Sitten, Zum ewigen Frieden, and more |

## Usage

Run the script to generate `alle_klassiker_deutsch.txt` (~20–30 MB):

```bash
python3 download_klassiker_de.py
```

No external dependencies — standard Python 3 only.
